Rendszeralap Backup

Rendszeralap Backup is a private backup utility operated by Veronika Lux for her own account. It stores encrypted backups in her Google Drive and supports restoring those backups. It is not a public service and does not accept other users.

Google Drive access

The integration requests two permissions: drive.readonly, to read and verify existing backups, and drive.file, to create and manage files authorized for this application. The read permission can technically read all files accessible through the authorized Drive account; the backup workflow is configured to use its designated backup repository.

The integration uses offline authorization so that the backup process can renew access tokens without an interactive login. Authorization can be revoked from the account's Google third-party connections settings. Revoking access stops future API access; it does not itself delete stored backups.
