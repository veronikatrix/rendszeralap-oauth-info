Privacy policy — Rendszeralap Backup

Effective date: October 14, 2026
Operator and contact: Veronika Lux, luxveruska@gmail.com

Purpose and users

This integration is a private backup tool for the operator's own Google account. It is not offered as a multi-user service.

Google data access and use

The integration uses drive.readonly to list and read existing backup objects, and drive.file to create and manage files authorized for this application. The read permission technically covers all files accessible to the authorized account. The configured backup workflow uses a designated backup repository to store encrypted backups and verify restoration. It does not use Drive data for advertising, sale, profiling, AI processing or model training.

Storage and processing

Backup data is encrypted with restic before upload to Google Drive. Backup creation and restoration take place on the operator's computers or hosted backup server. During restoration, decrypted data is processed in private working directories. OAuth client credentials and tokens are stored separately from the backup contents in private credential files; they are not part of this website.

Service providers and sharing

Google Drive stores the encrypted backup objects and handles Google authorization. A Hetzner-hosted server is used for the operator's backup workflow. These providers process data under their respective service terms. This integration does not sell Google user data, disclose it to advertisers, or provide it to other users.

Retention and control

Backups remain in the operator's Drive until she deletes them. This integration does not promise automatic deletion after a fixed period. The operator can revoke OAuth access from her Google account's third-party connections settings. Revocation prevents future API access once effective; it does not delete existing backups or local restored copies. Deletion of those copies is a separate owner-controlled action.

Security and updates

The backup encryption key is kept separately from the encrypted repository. New OAuth credential files are restricted to the designated operator or backup process. This policy will be updated if the integration's data practices change. Questions or requests can be sent to the operator's contact address above.
